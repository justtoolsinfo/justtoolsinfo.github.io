Things that often go wrong

Time zones: cron uses the server’s time zone, GitHub Actions always uses UTC, and EventBridge rules run in UTC. Check the next runs in UTC if your job runs at the “wrong” hour.

Both day fields in Unix cron: 0 0 1 * 1 runs on the 1st and every Monday, not only on Mondays that are the 1st.

Day numbers: Monday is 1 in Unix and Spring but 2 in Quartz and AWS. Using names like MON avoids mistakes.

FAQ

Questions about Cron Expression Generator

Where does Cron Expression Generator run?

Cron Expression Generator runs in this tab on Toolspire. What you type or drop in is not sent to us and is not stored on a server.

How do I run a cron job every 5 minutes?

Use */5 * * * * in Unix cron. In Quartz it’s 0 */5 * * * ?, in Spring 0 */5 * * * * and in AWS */5 * * * ? *.

What does * * * * * mean?

Every minute. The five fields are minute, hour, day of month, month and day of week; * means “every”.

What is the difference between Unix cron and Quartz cron?

Quartz adds a seconds field at the start (and an optional year), numbers days of the week 1–7 starting with Sunday, needs a “?” in either day-of-month or day-of-week, and supports L, W and #. The tool converts between them.

How do I schedule a job on the last day of the month?

Use L in day-of-month in Quartz, Spring or AWS, e.g. 0 0 0 L * ?. Standard Unix cron has no last-day option; a common workaround is to run daily on days 28–31 and check the date in the script.

Why does my GitHub Actions schedule run at a different time?

GitHub Actions cron is always in UTC (and may start a few minutes late when busy). India is UTC+5:30, so 9:00 AM IST is 30 3 * * *. Switch Next runs to UTC to check.

Can cron run every 30 seconds?

Not standard Unix cron — its smallest unit is a minute. Quartz and Spring have a seconds field: */30 * * * * ? (Quartz) or */30 * * * * * (Spring).
